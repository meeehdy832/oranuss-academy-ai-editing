# Reference shots (19 unique images in reference/, Nov 2026)

Mobile-app UI showcases (health, fitness, courses, smart home, journaling, chat, booking).

What repeats across them, and how we used it:
| In the references | In our animation |
|---|---|
| Soft single-colour canvas (lavender, pale blue, cream), sometimes a light pattern | lavender canvas with slow blurred pastel blobs |
| White rounded cards, very soft shadows | `card()` |
| Phone mockups, straight or slightly tilted, 1–3 per shot | `phone()` with a UI screen built from cards and skeleton lines |
| Big stat number + small label; progress rings; bar charts with one highlighted bar | `ring()`, `bar()`, hero bar in purple |
| Colourful category tiles with a big glyph (purple, orange, yellow, green, coral) | `tile()` |
| Date chips / steps with one active dark or purple pill | `stepper()` |
| Pill tabs and pill buttons, segmented controls | `pill()`, tab switch in the products beat |
| Avatar stacks and lists with action icons | `avatar()`, client list |
| Clean geometric sans, dark ink titles | Avenir Next Heavy / Demi Bold |

Brand names and app content in the shots were not copied; only the visual language.
