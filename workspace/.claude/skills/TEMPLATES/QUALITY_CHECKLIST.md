# Reel delivery checklist

Developed by Mehdi ORANUSS | Powered by Claude

- [ ] The original VO is intact; duration and scene order are accurate.
- [ ] Captions say what the person **actually** said, not an ASR guess.
- [ ] Latin Darija, French and English are spelled correctly.
- [ ] Animations demonstrate the current spoken idea (not generic stock footage).
- [ ] Real UI recordings are correctly cropped and technically accurate.
- [ ] No account names, chat history, emails or other private information leaks.
- [ ] Reference informs style but is not copied literally.
- [ ] Brand logo, typography and colors match supplied assets.
- [ ] On-screen text is legible on 9:16 phones and avoids platform overlays.
- [ ] SFX/music are licensed, balanced and quieter than VO.
- [ ] Preview is a verified playable MP4 with no black/glitch frames.
- [ ] Final is only exported after approval, under a new filename.
