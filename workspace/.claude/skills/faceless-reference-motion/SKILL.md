# Faceless educational motion graphics

Developed by Mehdi ORANUSS | Powered by Claude

Use when building scenes or revising motion graphics for tutorials.

1. Analyze reference **style**: motion speed, UI card treatment, typography, transitions, spacing and pacing. Do not copy original creator's exact layouts, facecam, captions, watermarks or logos.
2. Storyboard every meaningful sentence: `(spoken phrase, start/end, visual proof, asset or original animation, transition, caption)`.
3. Prefer **real supplied screen recordings** for actual Claude Desktop and Windows interfaces. Trim dead time, add clean cursor zoom/click emphasis, crop private info. Never depict invented UI steps as factual screenshots; for absent footage use clearly stylized, non-literal interface cards.
4. For missing shots, animate folders being created and named; files moving into input/reference; reference analysis; UI workflow steps; transcription; timeline edits; review corrections; MP4 delivered to output.
5. Use original Remotion/React compositions if those tools are available. Keep elements editable, separate scenes into components, use composition dimensions 1080×1920 at 30 fps, and sync to real voice timing.
6. Match supplied color palette and logo. Anchor the logo subtly near the bottom, above potential Reels controls and away from captions. Keep text high-contrast, legible on a phone, with no excessive glow.
7. Audio: use licensed/supplied background music where available and subtle original SFX on actual clicks/movements. Voiceover must dominate the mix.
8. Opening hook: if actual video examples exist in `input/hook-videos/`, play those assets inside tasteful framed compositions instead of fake video placeholder graphics. Respect reuse permissions.
9. Show a draft preview to inspect visuals against script. Do not render final without checking pacing, missing frames and crop issues.
