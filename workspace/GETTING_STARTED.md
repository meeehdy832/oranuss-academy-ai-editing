# Getting started

> Developed by Mehdi ORANUSS | Powered by Claude

This folder edits Oranuss Academy videos with **Claude Code**. You give Claude the footage or voiceover; Claude plans the edit with you, builds it in code and renders the MP4. Built on macOS (Apple Silicon).

## 1. Install the tools (once)

| Tool | Why | Install |
|---|---|---|
| Claude Code | runs the edit | the Claude desktop app (Code tab) or the `claude` CLI |
| ffmpeg-full | cutting, ASS subtitles (libass), mixing, encoding. Scripts call `/opt/homebrew/opt/ffmpeg-full/bin/ffmpeg` | `brew install ffmpeg-full` |
| whisper.cpp | Darija transcription with word timings | `brew install whisper-cpp` |
| whisper model | large-v3, 2.9 GB, goes in `project/models/ggml-large-v3.bin` | download `ggml-large-v3.bin` from huggingface.co/ggerganov/whisper.cpp |
| Python 3 | build scripts (standard library only, nothing to pip install) | comes with Homebrew / macOS |
| Node.js 18+ | HyperFrames, the HTML + GSAP engine for the 3D glass style | `brew install node`; then `npx hyperframes doctor` downloads its Chrome |
| Xcode Command Line Tools | compiles the macOS Vision helpers in `project/tools/ves/` | `xcode-select --install` |
| Fonts | Graphik Arabic (Arabic text) | double-click the `.ttf` files in `brand/fonts/graphik-arabic/` |

Avenir Next and the Arabic system fonts come with macOS; Poppins is bundled with HyperFrames.

## 2. Make a video

1. **Put the files in:**
   - camera footage → `input/recordings/`
   - voice-only audio → `input/voiceover/`
   - music → `music/`
   - style references (images or clips) → a style folder in `reference/styles/<long|short>/<style>/examples/`
2. **Open this folder in Claude Code** and ask, for example: *"Edit the video in input/recordings in the purple-3d-glass style, 16:9 for YouTube."*
3. **Answer Claude's questions** (feel, hook, captions, length, music…). Claude writes the plan to `output/<video>/PLAN.md`.
4. **Approve the plan.** For each paragraph of the script: your own idea, "Auto", or no graphics.
5. **Review the preview** (`output/<video>/<Name>-PREVIEW-v1.mp4`) and ask for changes; each round is a new version.
6. **Approve.** Claude renders `…-FINAL.mp4` at the source resolution.

Claude also writes `caption_uncertainties*.md` next to the video: words it could not hear clearly. Tell it the right words before the final.

## 3. The styles

| Style | Look | Engine |
|---|---|---|
| purple-3d-glass | frosted glass, glossy 3D purple objects, glow (newest, used for YouTube) | HyperFrames (`project/hf/`) |
| pastel-app-ui | light mobile-app UI cards, phone mockups | ffmpeg + ASS (`project/styles/pastel_ui.py`) |
| purple-glass | dark navy + neon purple glass, kinetic captions | ffmpeg + ASS |
| premium-serif | dark and moody, bold + italic-serif captions | ffmpeg + ASS |
| dark-green | emerald and mint, frosted lower panel, checklist tracker | ffmpeg + ASS |

Each style has its recipe in `reference/styles/<long|short>/<style>/STYLE.md`. To add a new look: drop examples in a new folder `reference/styles/<long|short>/<name>/examples/` and ask Claude to write its STYLE.md and a short test.

## 4. Where things are

See [README.md](README.md) for the full folder map and the list of finished videos.

- **Originals:** `input/`. Nothing there is ever changed.
- **Deliverables:** `output/<video>/`.
- **Scratch:** `project/work/` (regenerated by the build scripts, safe to delete per video when you need space).
