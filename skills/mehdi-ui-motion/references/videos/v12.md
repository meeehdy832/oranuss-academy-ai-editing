# v12 — Apple Wallet concept "Bank slowing you down?" · 720×720 · 29.97fps · 606f (20.2s) · by dnyxstudios

Sequence of 9.4 s played **twice** (0–281, 281–562) + end card.

## Story (one loop)
| frames | beat | what happens |
|---|---|---|
| 0–8 | ripple | soft blue gradient with a ripple/wave distortion that clears to white (liquid reveal) |
| 8–24 | copy 1 | "Bank [bank-icon chip] slowing" — a small light-blue icon chip sits **inline** between the words; text slides from right |
| 24–60 | copy 2 | second line "you down?" + a Wallet app icon appended inline at the end; gentle push-in |
| 60–90 | UI build | segmented pill row "+ Add Funds · ↗ Send · ⟳ Convert" fades in **from tiny & blurred** (distant → near) |
| 90–135 | interaction | "Send" turns blue (selected), arrow cursor glides in (ease-in-out ~15f) and hovers → a **light-blue focus ring** grows around the button; click squish; camera pans left as the row slides |

| 150–210 | **odometer** | the arc rotates like a wheel (coins travel along the arc) while the amount changes 900 USD → 770 EUR → 659 GBP; each character **rolls vertically** with a stagger (wave across the string), blue while rolling, gray when settled |
| 210–222 | exit | coins and amount blur + drift down |
| 222–262 | word roll | Apple logo + a vertical slot list: "Pay" → "Earn" → "Apple Wallet"; previous and next words visible above/below (faded, cut by a gradient mask), camera keeps zooming in |
| 262–281 | settle | "Apple Wallet" small, shrinks to center → loop |
| 562–605 | end card | dnyxstudios |

## Design
- White, Apple-y. SF Pro text, regular weight, gray #8E8E93 for inactive, black for active, iOS blue #4A90F0 for selection.
- Pills: #EBEBEB light gray capsules, 18px label + SF Symbol icon; selected = filled blue + white label + focus ring (blue at 25% alpha, +8px).
- Coins: flat light-gray circles with dark gray currency glyph — neutral, lets the number be the hero.
- Inline icon chips inside sentences (bank, wallet) = visual punctuation.

## Motion
- Odometer per-character roll (stagger 1–2f, each roll ≈6f, blue during motion).
- Wheel/arc carousel for a set of options (coins).
- Picker-wheel word swap with masked neighbors (same family as v01's app-chip roll).
- Hover → focus ring → press → release (four-state micro-interaction) on every click.
- Loopable structure: end state ≈ start state.
