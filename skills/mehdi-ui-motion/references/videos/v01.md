# v01 — "New way of searching" (AI search → files) · 720×720 · 30fps · 359f (12.0s)

## Design
- Stage: flat light gray **#EFEFEF**, no texture. UI pills: same gray, slightly lighter top, **very soft large shadow** (neumorphic-lite), fully rounded.
- Type: SF Pro / Inter-style geometric sans, regular weight for UI, medium for kinetic sentence. Near-black text (#1d1d1f-ish) on light, white on black end card.
- Accent color only appears as **gradients** (rainbow underline, bronze chip, blue search glow) — the base stays neutral.
- Real-looking content (design-file thumbnails: posters, branding boards, watch ad) gives credibility; each card has a small folder icon + filename label above it (Finder/Spotlight language).
- The end card switches to pure black for contrast; brand mark (memoji) is the only colored thing.

## Motion notes
- **Morph chain instead of cuts**: line → capsule → dot → caret → text → chip → sliver → word. Only ONE hard cut in 12s (304).
- Camera is always moving: push-ins during typing, follow-pan with the caret, fast pull-back to reveal.
- Fast moves (whip at 165, pull-back at 187, collapse at 116) carry strong motion blur; slow holds are sharp.
- Picker-roll for "options": vertical slot motion with blurred neighbors.
- Depth of field: when zoomed in, the frame edges are blurred (tilt-shift look) to focus on the active word.
- Exit by **vignette to black** (edges first) rather than a fade.
