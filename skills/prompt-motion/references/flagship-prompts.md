# Prompt Motion — Flagship Blueprints Reference

## #2 Shape Morphing Through UI States (@twoclipping)
- **Direction:** Dribbble-level UI motion. One shape, never cut: every state is the same element morphing size, radius, and color while content swaps cleanly. Cursor drives every change with clicks and drags. Light warm-gray canvas, black & white + 1 accent, clean UI sans.
- **Tech:** Pure `seek(t)`, closed-form step-response springs, dual-spring liquid tab/toggle edges (leading edge stretches ahead of trailing edge), direct manipulation during drag.

## #5 Photo Print App Launch (@twoclipping) & #11 Launch Sting (@notdwd)
- **Direction:** Apple-keynote continuous take. Nothing fades or cuts randomly — iris wipes, floods, and shared-element morphs connect every beat. Directional blur follows speed.

## #6 / #33 Landing Page 3D Scroll (@twoclipping)
- **Direction:** 14.5s WebGL2 3D fly-over at 56° tilt over a bright studio floor (`#f9fbfb`), `data-layer` cards lifting 20–130px with soft shadows, golden-angle DOF blur, overhead strip → hero dive → 2-line title card.

## #28 TechHalla Kinetic Type Bumper (@techhalla)
- **Direction:** 20s 1080×1080 loopable street-poster bumper (`#0A0A0A`, `#FF2BD6`, `#B8FF00`). 3-font system (Display, Grotesque, Mono), seeded glyph scramble, letterform mask wipes, 2–4px print misregistration on impact frames.

## #29 Orange Dot & #30 White Ball Loop (@ultimaxbt, @rossaxbt)
- **Direction:** One continuous physical dot/ball linking toggle → spring graph → kinetic type / slider → notifications → keyboard → camera pull-back loop (`frame[0] == frame[last]`).

## #44 Ora 2 AI Voiceover Launch (@rossaxbt)
- **Direction:** Word-level Whisper timestamps, liquid glass controls (frost + edge refraction + sheen), 16th-note image swaps, 3-band sidechain music ducking, `-14 LUFS`.

## #73 Spotify Product Film (@brainextends)
