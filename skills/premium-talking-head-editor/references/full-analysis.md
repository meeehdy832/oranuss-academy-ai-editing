## الجزء 2: قواعد الستايل (Rule book)

### 2.1 الألوان (`2_style_examples/01`)
1. جمع ألوان الأكسنت من الفيديو الخام: القميص، اللمبة، النافذة، الحيط.
2. اختار لون واحد. فالمثال: اللمبة `#FACE7C`.
3. استخرج منو:
   - **Gold** (vibrant accent): `#F2E186`
   - **Orange** (dark, rich accent): `#8E4A2B`
4. خد **White** و**Black** وصبغهم بنفس حرارة اللون. الأبيض `#F6EBE2`. الأسود غامق مايل للدفء، والقيمة ديالو ما واضحاش فالشاشة.
5. فالخطة كاينين 4 باليطات جاهزين (`3_workflow_screens/07`): Green + cool grey، Oxblood + peach، Gold + light، **Gold + dark orange** (هادي اللي اختار).
6. **كيفاش كيتوزعو فالنتيجة النهائية:**
   - A-roll: صورة غامقة، النص الرقيق أبيض، والكلمة الخاصة **Gold**.
   - مشاهد الشاشة الكاملة: خلفية **كريمية (White المصبوغ)**، والدوائر والـpill **Orange/بني**.
   - B-roll: الصورة غامقة، والكلمة الخاصة Gold ولا بيضاء.

### 2.2 الخطوط (`2_style_examples/02`)
- **عائلة وحدة فقط.** فالخطة كاينين 3 اختيارات: Sans only (PP Neue Montreal)، Sans + serif، Serif only.
- النص الرقيق: وزن 300–400، صغير.
- الكلمة الخاصة: وزن 600–700، **حجمها حوالي 2 حتى 3 مرات** حجم النص الرقيق.
- الشكل اللي كيتكرر: سطر صغير رقيق فوق (مثلا "it's an") وسطر كبير بولد ملوّن تحتو (مثلا "inability to focus").
- كاينة بعض المرات **كلمة صغيرة ثالثة** تحت الكلمة الكبيرة على جنب، بحال "for two reasons" تحت "better at learning".
- فالمراجع كاين حتى Serif وScript (Montserrat Light caps، condensed serif). المثال: `3_workflow_screens/04`.

### 2.3 الهوك (أول ظهور لكل متكلم) (`2_style_examples/03–05`، `4_final_edit_frames/01`)
- الفيديو **9:16**. المتكلم فالنص الفوقاني، والوجه كيبقى فالوسط العمودي بتتبع الأنف.
- النص فالنص التحتاني تقريبا فـ60–75% من العلو، ومصفوف على اليسار.
- **الكلمة الأقوى** (كلمة سلبية ولا سؤال) بالـGold وبولد. مثلا "improving memory"، "Brain fog".
- **بطاقة الاسم:** تحت اليسار، مستطيل **أبيض** فيه السمية بالأسود (Chris Williamson)، وتحتو سطر صغير بالمنصب (Host of Modern Wisdom / Neuroscientist, Stanford).
- **أنيميشن الكلمة:** الحروف كيبانو بـglitch (فالفريم 19:51 كيبان "i pr i m mo y" يعني الحروف كيطلعو بشكل عشوائي). من بعد الكلمة كتمشي بـglitch والكلمة الجاية كتجي.
- فاش كيتبدل المتكلم (cut من Chris لـHuberman)، كيتعاود نفس النظام: نص جديد + بطاقة اسم جديدة.

### 2.4 سوبتايتل باقي الفيديو (`3_workflow_screens/11`)
- **6–8 كلمات** لكل "صفحة"، ولا جملة وحدة.
- **كلمة خاصة وحدة** فكل صفحة.
- الأمثلة من الـdesign sheet: "**Brain fog** / is not a specific thing"، "it's an / **inability to focus**"، "what it means is that / **people can learn to focus**"، "to get alert, there are / **many things** / you can do"، "exercise makes you / **better at learning** / for two reasons"، "you're going to come out of that / **more alert**"، "and dopamine is a / **critical component** / for learning".
- **جمل الانتقال** بحال "what does that mean?" كتكتب **صغيرة ورقيقة بلا كلمة خاصة**، وكيدار **punch-in** (close-up) على الوجه (20:07).
- بعض الصفحات فيها **كلمة وحدة صغيرة** على جنب المتكلم ("exercise"، "here are…") كتربط بين المشاهد.

### 2.5 B-roll (فيديو) (`2_style_examples/06–07`)
4 أشكال:
1. **كليب كامل + rough texture + تغميق وبلور على الحواف + نص سينمائي فالوسط** (serif caps، مثلا "CONSUMER EXPECTATIONS / ARE HIGHER NOW").
2. **سهم + نص** كيشير للموضوع.
3. **Tracked selector box:** مربع رقيق أبيض فيه زوايا كيتبع العنصر (كاس، قهوة، وجه)، مع **سهم منحني** ونص صغير (مثلا "Alcohol"، "caffeine"، "People with ADHD").
4. **Leading lines + camera pan** لعرض نص فقط.

### 2.6 الصور (`2_style_examples/08`)
- **Side by side:** الموضوع فجهة والنص السينمائي فالجهة الأخرى، وأحيانا النص **من ورا** الموضوع.
- **Subject in center:** نص سينمائي من ورا الموضوع ("we hit our 30s")، ولا **stroke كريمي يتبع شكل الموضوع** مع نص ضخم فوقو ("I want to LOOK THE BEST").

### 2.7 الشاشة الكاملة (Full-screen)، 4 أنواع
| النوع | التصميم | امتى تستعملو |
|---|---|---|
| **#1 Two Object Alignment** (`09`، `10`) | Side by side: كائن فجهة بـcast shadow والنص فالجهة الأخرى، مع blur وfade على الحواف. Upper/lower: النص فوق ("PEOPLE BUILD TRUST") وعنصر تصميم كياخد من الثلث السفلي حتى للوسط، مع filler elements حواليه | المتكلم كيتكلم على شيء واحد |
| **#2 Graphs & Numbers** (`11`) | graph فالوسط ونص حواليه، ولا bar graph فالنص التحتاني ونص نقي فوق ("If you had 200 followers")، ولا patterns ديال illustrations كتتراكم | زيادة ولا نقص فالأرقام |
| **#3 Real Elements** (`12`) | صور حقيقية كتلصق فخلفية كريمية بـ**stroke نقي**، ولا مقسومة فـlayout والنص فالوسط ("and apply them / women's") | تجربة ولا حاجة خاص المشاهد يشوفها |
| **#4 One Object Centered** (`13`) | عنصر واحد فالوسط + cast shadow + depth elements فالحواف (أقواس) + نص serif ("Fibroblast Cell") | عنصر واحد فقط |

### 2.8 العناصر اللي كتكرر (DNA ديال الستايل)
- خلفية **كريمية** فمشاهد الشاشة الكاملة.
- **أقواس/حلقات بنية رقيقة** فالركن الفوقاني (depth elements).
- **Cast shadow** طويل ورطب.
- **أعمدة ضوء/blur عمودية** تحت العناصر.
- **دوائر برتقالية** فيها جزيئات 3D صغيرة.
- **Pill غامق** فيه كلمة ("Threshold") مع خط منقّط.
- **حلقة ذهبية رقيقة** حوالين الموضوع فالـB-roll (20:21).
- **مستطيل بني** ملوّن وراء الكلمة الخاصة ("learn to **focus**"، 20:13).
- الحواف ديال كل مشهد مغمقة وبلورية (vignette).

## الجزء 7: برومبتات جاهزين للـAI ديالك (إنجليزية)

**A: تدريب ستايل جديد**
```
I want you to learn this editing style. I've uploaded N reference edits and a Figma board breaking down its design.
1) For each reference: a frame-by-frame breakdown with a word-by-word transcript. Table: # | WORD | START(s) | FRAME | SCENE | WHAT IS ON SCREEN (font, size in px, color HEX, motion, frames).
2) Study: (a) design — colors, layouts, effects, proportions, fonts; (b) animation logic — types, timing, speed, motion curves; (c) animation behavior relative to the script (which words trigger what).
3) Scan the Figma board and write a complete rule book of the style.
4) Build an Inspiration Guide: group every animation into categories. For each animation create a folder named P<ref>-A<n> '<word>' <short description>, containing still.png, strip.jpg (keyframe sheet), notes.md (category, source frames/seconds, words, keyframe, exact construction).
5) Build a Lookbook (palettes + font styles and how to use them).
6) Create a short-form editing skill that takes a raw video and, with my plan, produces edits in this exact style.
```

**B: تحضير الكليب**
```
Do a word-by-word, millisecond-level transcript of this clip, then a frame-by-frame breakdown.
Cut all silences and bring it down to ~60 seconds.
Make it vertical 9:16 for Instagram: track the speaker's nose and keep it on the vertical center line through every cut.
Deliver the raw cut, ready to be edited.
```

**C: وثيقة التخطيط**
```
Using the transcript, create a planning document.
Top: "The look" — 4 palette options extracted from the footage (accent → vibrant + dark version + tinted white + tinted black) and 3 font-family options (sans only / sans+serif / serif only).

```

**D: التنفيذ**
```
Here is my completed plan. Edit the video in the trained style.
1) List every asset needed (images, illustrations, B-roll, icons) and collect them.
2) Build all captions first and send me a caption design sheet to review.
3) Build each scene one by one and show me each for approval.
4) Final render 1080p synced to the voice; send me the export.
```

**E: الصوت**
```

Rules: special words get a pop/notification, normal words a soft click or nothing; glitch text gets micro-glitch/mechanical SFX; whooshes peak exactly on the cut; camera-shutter on still-image pans; music drops on the first speaker cut; keep SFX between -9 and -19 dB.

```
