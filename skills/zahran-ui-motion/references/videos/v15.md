# v15 — Music recognition widget loop (Shazam-like) · 720×720 · 30fps · 340f (11.3s) · by dnyxstudios

Loop of ~5 s played twice (0–152, 152–305) + end card. **One single object morphs the whole time.**

## Morph chain (one loop)
| frames | state | details |
|---|---|---|
| 0–5 | spawn | a blurred tile pops from nothing at center (scale 0.6→1, blur 12→0) |
| 5–42 | video tile | rounded (radius ≈ 28px) video of people dancing; a white "● Recording ◉" pill with a red mic badge slides up inside the tile; slow push-in (tile 30% → 45% of frame) |
| 42–56 | accelerate | fast push-in and the video tile slides up and out of frame (ease-in, velocity peaks at 56) while the Recording pill stays in place |
| 56–88 | listening widget | the pill **morphs** into a white widget card: animated blue **waveform bars** (equalizer moves every frame), app badge, "Searching…" types letter by letter, timer "1:39:67" ticks |
| 88–92 | color morph | widget shrinks and darkens (white → gray → charcoal) while changing aspect |
| 92–108 | result pill | dark pill: album art + "Wish (feat. Trippie Redd)" — the words **bounce in one by one with vertical offsets** (word wave) + "E Diplo, Trippie Redd" |
| 108–116 | color morph 2 | pill turns blue, contracts horizontally into a circle |
| 116–150 | button | blue circle with "+" — breathes; arrow cursor enters (ease-in-out ~18f), changes to hand, press: button scales 1 → 0.9 → 1.15 |
| 150–155 | expand | button blows up into the video tile (loop seam) |
| 306–339 | end card | dnyxstudios |

## Design
- Light gray stage (#E4E4E9) — Apple system gray 6. One object, centered, never more than ~45% of the frame.
- Brand-neutral iOS components: white card with soft shadow, charcoal (#2C2C2E) pill, system blue (#4A63E7) button, red (#E5243B) record badge.
- Each state has a different **shape + color + content**, but the transition is a single continuous morph.

## Motion
- Morph = interpolate width, height, radius, background color at the same time (≈6–8f), with content crossfading at the midpoint (old fades out in 3f, new fades in 4f after).
- Idle motion inside each state (waveform, typing text, ticking timer, breathing button).
- Speed curve: slow push (holds) → sharp acceleration into a morph → settle with slight overshoot.
- This is the "Dynamic Island" language: one container that keeps changing what it is.
