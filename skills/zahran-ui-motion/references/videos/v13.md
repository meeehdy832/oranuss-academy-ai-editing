# v13 — Apple Calendar concept "Plan Smarter." · 720×720 · 30fps · 282f (9.4s) · by dnyxstudios

## Story
| frames | beat | what happens |
|---|---|---|
| 0–3 | **glitch open** | 3 frames of CRT static / scanlines (dark, light, dark) — a "channel switch" hook |
| 3–20 | icon | Calendar app icon ("Tue 14", red day label) pops at center on light gray #E5E5EA, digits roll in |
| 20–56 | widget | a dark day-view widget slides up from **behind** the icon (layered, icon stays in front-left), slight 3D float |
| 56–60 | scale-through | the dark widget scales up past the frame edges → becomes the whole dark scene (#232323) |
| 60–76 | day view | "MONDAY 7" + timeline with translucent colored event blocks (yellow "Video edit sesh", green "Weekly Meeting", blue "Salto practice"), each with a bright left bar — Apple Calendar dark mode |
| 76–96 | **letterbox** | black cinema bars slide in from top and bottom, camera pushes in; a notification "You have 5 minutes!" slides out from behind the events, its text typing |
| 94–100 | whip | bars retract, vertical whip with heavy streak blur |
| 100–128 | map tile | a Maps widget (red pin, light map) tumbles in **rotated in 3D**, settles straight |
| 128–156 | nav widget | a black rounded widget with turn-by-turn arrows (↰ ↑ ↑ ↱) + "Sports Arena"; arrows highlight one by one |
| 156–186 | avatar map | a dark navy map tile with an avatar pin rotates in 3D, then shrinks to a dot |
| 186 | cut | white frame with Apple logo (flash) |
| 191 | cut | black " Calendar" (white type) |
| 207 | cut | white "Plan" |
| 214 | cut | black "Plan Smarter." — then shrinks |
| 230–281 | end card | dnyxstudios with bloom |

## Design
- Dark mode Apple palette: #1C1C1E/#232323 base, event colors at ~35% opacity fill + 100% left bar (yellow #E5C33D, green #5BBF4B, blue #3A9BDC), red day label #FF453A.
- Widgets: squircle corners (radius ≈ 22% of size), soft drop shadow even on dark.
- Logo/tagline sequence alternates **white / black** full frames on each beat.

## Motion / pacing
- Hook = 3f glitch. Ending = 4 hard cuts in 1 s (fast typographic montage) — energy peak right before the logo.
- Letterbox bars = "cinematic attention" for the key UI moment (notification).
- 3D tumble entrances (rotateX/rotateY 30–60° → 0 with blur) for widgets.
- Scale-through a card to enter its content (same idea as v07's window portal).
