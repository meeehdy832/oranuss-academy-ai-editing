# v03 — "PINNED" social app promo · 720×1280 (vertical) · 30fps · 269f (9.0s)

## Format trick
Square-ish content card (rounded 24px corners, white) centered in a 9:16 frame. The top/bottom bands are a **blurred, enlarged copy of the live content** (ambient fill) — so when the card turns blue/orange/green the bands glow the same color. Handle "@creatoroly" in light gray under the card.

## Design
- White card, navy (#0E1A3B-ish) bold sans headlines, tight tracking, 2-line centered max.
- Brand blue (#2F6BFF-ish) used for the logo glow, caret block, button, slider gradient (cyan → blue).
- Emoji circles: each chip's background = pastel of the emoji's main color → harmonious but colorful row.
- Real map UI as context, blurred at the edges.

## Motion
- **Entrance by assembly** (particles → blob → letters) is the hero move for a brand reveal.
- Color-temperature shifts per scene (white → pale blue → mint → warm orange → green → blue) via the ambient bands; it reads as scene changes without cuts.
- Placeholder bars → text = "loading" metaphor that keeps motion going.
- Every element morphs into the next (button → card → line → slider).
- Fast scene changes ≈ every 1.5 s, each with a 4–6f blur transition.
