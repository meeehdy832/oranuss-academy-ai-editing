# v19 — Pinterest concept "Need inspo?" · 720×720 · 30fps · 266f (8.9s)

## Story
| frames | beat | what happens |
|---|---|---|
| 0 | **brand-color flash** | 1 full frame of Pinterest red (#E60023) |
| 1 | dark red | 1 frame dark burgundy |
| 2–4 | flicker | "inspo?" flickers white / black / black (hard alternation, 1f each) |
| 5–9 | build | "Need" slides in, 3 rounded image cards (mountain / grass / branch) pop above the text from small → full, tilted (−8°, 0°, +8°) fanned like a hand of cards; white with a faint pink floor gradient |
| 9–45 | hold | cards gently breathe; text sits; slow push-out |
| 45–55 | phone | cards and text blur out, a phone slides up fast (flow peak 12) showing a Pinterest masonry feed (Snowy mountains, Lock in twin…) |
| 55–88 | feed | camera scrolls the feed (slow pan up), pins fade in |
| 88–100 | long-press | camera dives in to a pin; the pin dims; the Pinterest **long-press radial menu** appears (circle buttons: ♡, share, hide, pin) |
| 100–140 | radial | finger hovers each option, the label above changes ("See less", "Share", "Save"); the active circle grows; "Save" selected (pushpin icon) |
| 140–142 | cut | white |
| 142–200 | board | "motion design board" (black + italic "board" on its own line); small thumbnails of the creator's own past videos fly in around the text from different directions and settle in a loose ring, each at a different size (collage) |
| 200–228 | organize | "organize it" — thumbnails rearrange into a tidy column/grid below the text (chaos → order = "organize") |
| 228–232 | wipe | thumbnails slide away |
| 232–244 | **logo draw** | the Pinterest "P" is drawn as a brush stroke (red), first the vertical stem then the bowl |
| 240–265 | lockup | "with pinterest" blur-in under the P; hold |

## Design
- White + Pinterest red; pink floor tint near the bottom ties to the brand.
- Rounded image tiles (radius ≈ 16px) with a 4px white border and soft shadow = "pin" look.
- Black geometric sans, regular weight, italic second line for rhythm.

## Motion
- Opening with **brand-color flash + 1f flicker** (4 frames) = scroll-stopper.
- Long-press radial menu as interaction storytelling (hover → label change → select).
- Chaos → order animation to illustrate "organize".
- Logo stroke draw at the end (path trim 0→1 in ~10f, ease-out).
