## Design
- Warm cream background (#FFFBF3) = editorial/web. Black Helvetica-like grotesk for both headline and website.
- Real website layout (12-col grid, 3 product columns with generous gutters, 2-column story section) — designing the website *inside* the video shows the product (Framer).
- Blue (#2E6BFF) only for editor UI hints (selection handles, glyphs).

## Motion
- **Converging glyphs** → sentence (chaos → order).
- Sentence opens a gap for inline media (text reflows around the media).
- Site build = rapid stagger of many small elements in 15–20f; each element ease-out from a 30–60px offset.
- Zoom-out while typing (start huge with the caret, end small) — gives a typed line a camera move.
