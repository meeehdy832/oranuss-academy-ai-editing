# v05 — "Use Concerta." (concert app) · 720×720 · 29.97fps · 495f (16.5s) · by dnyxstudios

Same template family as v01 (search bar → rainbow line → dot → caret). The 7.5 s sequence plays **twice** (0–228 and 228–450) so it loops on Instagram, then a studio end card.

## Design
- Pure white stage. Navy-black (#0B1B2B) headline in a clean grotesk (SF Pro/Inter Medium), tight tracking.
- Widget card recipe: pastel fill of a hue + 1px border of the same hue slightly darker, radius ≈ 28px at 720 width, thumbnail radius ≈ 16px, title bold 18px black, date 12px gray, a small emoji badge top-right. Four cards = four hues, same lightness → harmony.
- Blue (#1677E5) for interaction feedback (selection, caret, underline).

## Motion (measured)
- Grid entrance flow curve: slow rise then sharp peak and long tail → pills **accelerate in** and the cards **decelerate to rest** (overall bell, skewed to ease-out).
- Exit at 192–200: velocity rises gradually (≈15f) and ends abruptly at the morph → **accelerating exit** (ease-in) that hands off directly into the next shape. No stop between exit and next entrance.
- Loop seam is invisible: the last frame of the logo shrink matches the first frame of the bar fade-in.
