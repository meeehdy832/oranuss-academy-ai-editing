# Idea library: story patterns and visual metaphors from the 24 refs

Use these as building blocks. Each pattern lists the refs to re-read in `references/videos/`.

## Opening hooks (first 0–1.5 s)
1. **Question in small type** with something moving on frame 0 ("Need inspo?", "When did you last read?",
   "Lost your friends again?", "wait… what is this song?") (v17, v18, v19, v24).
2. **Glitch/flash open**: 1–4 frames of static, brand color or flicker, then the line (v13, v19, v11).
3. **Assembly**: particles/glyphs/blobs converge into a logo or a sentence (v03, v08, v09, v22, v10).
4. **Search bar starts**: Safari toolbar + rainbow line → dot → caret → typed question (v01, v05).
5. **Mood glow**: black, one colored light rising, giant UI digits (v02).
6. **Device rise**: a phone rises from the bottom edge with a glow (v21, v16).

## Transformations (the "turn")
- **Text → object**: the swipe-erase word becomes avatars (v18); a sentence is eaten by a comet into an icon (v23);
  a typed query becomes a selection block that drops into the answer (v05).
- **One object, many states** (morph chain): line → dot → caret (v01); tile → widget → pill → button (v15); pill → card → line → slider (v03).
- **Inside/outside**: push through a window/screen/orb (v07, v13, v14, v23); a scene shrinks into a widget (v18), an icon (v10) or a phone (v07).
- **Container breaking**: an element leaves its device (book cover out of the phone, v24); a notification wider than the phone (v10).
- **Device builds around content**: the island drops, then the phone body wraps the screen (v14).
- **Chaos → order**: scattered thumbnails snap into a grid (v19); glyphs converge into a sentence (v22).
- **One → many**: an inline image explodes into a collage (v09); one phone becomes a fan of phones (v17).

## Feature beats (show, don't tell)
- **AI search** → real result cards flying in one by one with folder labels (v01); a results page with hover/tooltip (v14).
- **Chat/assistant** → bubbles typing, a mascot participant, tapbacks (v20); a Siri banner typing request → reply (v21).
- **Money** → amount odometer + coin wheel (v12); a route on a world map between avatar pins (v10); a notification "You received $1500".
- **Health/data** → dark squircle widgets in a deck with big numbers and charts (v09).
- **Productivity** → calendar day view → notification with letterbox → maps → navigation arrows (v13).
- **Screen time / wellbeing** → big stat on a sky wallpaper → bottom sheet slider → blocked-apps diagonal track → live activity (v16).
- **Social / friends** → avatars with colored rings orbiting, gathering into a cluster (v18); emoji chips row + map pins (v03).
- **Music** → album squares rising, lyric words on a tilting phone, a fan of result phones (v17); listening waveform widget (v15).
- **Web builder** → the website assembles itself with stagger, with selection handles (v22).
- **Onboarding** → question cards with ‹ › carousel buttons and a cursor (v06).
- **Customization** → a slider moves while one word in the line swaps (v02).
- **Reading** → serif type, book texture, a cover flying out with chapter chips (v24).

## Endings
- **Logo assembly / draw**: a particle traces the logo path (v17); a brush stroke draws the logo (v19);
  a blob wobbles into the app icon (v11); parts lock together (v10).
- **Tagline small + logo + hold** ("Plan Smarter.", "with find my", "read more", "Use AI").
- **Studio end card**: black, white wordmark with bloom, slow scale-down (dnyxstudios, 1.3–1.5 s).
- **Creator signature**: memoji pops next to the last line (v01, v07, v23), "this is a concept. / by Oly :)" (v02).
- **Fast montage to logo**: 4 hard cuts alternating white/black frames with single words (v13).
- **Loop seam**: the end state equals the start state (v05, v12, v14, v15, v23).

## Thematic background ideas
- Background = the product's world: pool water + ducks for "Pool" (v04), clouds/sky for travel and calm (v07, v16, v24),
  map for location (v10, v18), book pages for reading (v24), wallpaper waves for macOS (v23), photo collage for creators (v21).
- Brand gradient as a soft mesh (Instagram pink/peach/lilac, v11).
- Neutral white/gray when the UI is the hero (most videos).
