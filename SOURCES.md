# Where every piece comes from

> Developed by Mehdi ORANUSS | Powered by Claude

This repo only holds Oranuss files. Everything else is installed by `install.sh` from its own official link.

| Piece | Source link | Installed with |
|---|---|---|
| Oranuss skills, workspace, installer | https://github.com/meeehdy832/oranuss-academy-ai-editing | `install.sh` (copy) |
| GSAP skills (gsap-core, gsap-timeline) | https://github.com/greensock/gsap-skills | `npx skills add greensock/gsap-skills` |
| HyperFrames skills (hyperframes, cli, registry, media-use, reverse-any-video, style-sampling…) | https://github.com/heygen-com/hyperframes | `npx skills add heygen-com/hyperframes` |
| HyperFrames engine (HTML + GSAP → MP4) | https://www.npmjs.com/package/hyperframes | `npx hyperframes@0.9.9` |
| earshot (listen to and judge sound, SFX bank) | https://github.com/Leonxlnx/earshot | `npx skills add` + `pip install git+…` |
| ffmpeg-full, whisper-cpp, node | https://brew.sh | `brew install` |
| Whisper large-v3 model | https://huggingface.co/ggerganov/whisper.cpp | `curl` (2.9 GB) |
| skills CLI | https://github.com/vercel-labs/skills | `npx skills` |
| Noto Kufi Arabic (free font, OFL) | https://github.com/google/fonts/tree/main/ofl/notokufiarabic | `curl` |
| Graphik Arabic (paid font) | https://commercialtype.com | not included: add your licensed files to `workspace/brand/fonts/graphik-arabic/` |
